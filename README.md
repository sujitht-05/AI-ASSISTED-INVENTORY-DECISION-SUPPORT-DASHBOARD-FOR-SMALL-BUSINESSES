# AI-ASSISTED-INVENTORY-DECISION-SUPPORT-DASHBOARD-FOR-SMALL-BUSINESSES

---

📌 Project Overview

-The AI-Assisted Inventory Decision Support Dashboard for Small Businesses is a web-based decision support system designed to help small businesses monitor and analyse their inventory more effectively.

-The system provides inventory information, stock-level analysis, AI-assisted insights, reorder recommendations, demand-related analysis, and supplier risk information through an easy-to-use dashboard.

-The main goal is to help small businesses reduce stock shortages, avoid excess inventory, and make better data-driven inventory decisions.

---

🎯 OBJECTIVES: 

- 📦 Monitor inventory levels efficiently
- 🤖 Analyse inventory data using AI-assisted techniques
- 📈 Predict future product demand
- 🔔 Identify low-stock products
- 📊 Detect overstock situations
- 🔄 Generate reorder recommendations
- 🏭 Analyse supplier-related risks
- 💰 Help reduce unnecessary inventory costs
- ⚡ Support faster and data-driven business decisions
- 📋 Provide an easy-to-use visual dashboard

---

✨ KEY FEATURES:

1. 📦 Inventory Management

- Add and manage products
- Monitor current stock levels
- Track inventory status
- Identify low-stock products
- Identify overstocked products

2. 🤖 AI-Assisted Demand Prediction

- Analyse historical inventory/sales information
- Estimate future product demand
- Provide inventory-related insights
- Support better purchasing decisions

3. 🔄 Reorder Recommendation

The system helps identify products that require replenishment and provides recommended reorder quantities based on inventory conditions.

4. 🏭 Supplier Risk Analysis

The dashboard includes a supplier risk analysis module to help identify potential supplier-related issues.

Supplier information can be analysed using factors such as:

- Supplier reliability
- Delivery performance
- Risk level
- Supplier-related inventory impact

5. 📊 Interactive Dashboard

The dashboard provides visual information such as:

- Total products
- Available stock
- Low-stock products
- Overstocked products
- Demand predictions
- Reorder recommendations
- Inventory trends
- Supplier risk information

6. 💡 Decision Support

The system converts inventory information into actionable recommendations to help business owners make better purchasing and stocking decisions.

🚀 HOW TO RUN THE PROJECT:

Method 1: Open Directly
•Download or clone the repository.
•Open the project folder.
•Open index.html in a modern web browser.

Method 2: Using VS Code
•Open the project folder in Visual Studio Code.
•Install the Live Server extension.
•Right-click index.html.
•Select Open with Live Server.
•The dashboard will open in your browser.
